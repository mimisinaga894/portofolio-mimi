Skripsi — bukan sekadar "bikin chatbot".

Academic Service Chatbot: aplikasi web yang menjawab pertanyaan mahasiswa berdasarkan dokumen resmi fakultas, dibangun dengan pendekatan Retrieval-Augmented Generation (RAG) dari nol sampai diuji ke pengguna.

Academic Service Chatbot — SIAssist

Final Year Project — Universitas Mercu Buana · 2026
RAG PIPELINE

PROBLEM

Mahasiswa kesulitan mendapat info akademik dengan cepat — harus mencari manual atau bertanya langsung ke bagian akademik.

SOLUTION

Chatbot berbasis RAG yang menjawab otomatis dan kontekstual, selalu merujuk dokumen resmi fakultas — bukan jawaban generatif acak.

ARCHITECTURE

LaravelWeb interface
→
FastAPIBackend / orchestration
→
ChromaDBVector database
→
Gemini APIResponse generation

RAG PIPELINE

  • Dokumen akademik diproses dan dipecah menjadi potongan teks (chunking).
  • Setiap potongan diubah jadi vector embedding, disimpan di ChromaDB.
  • Pertanyaan mahasiswa dicocokkan dengan dokumen paling relevan (retrieval).
  • Dokumen relevan + pertanyaan dikirim ke Gemini API untuk jawaban kontekstual.
